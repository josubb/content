Tus backups de vídeos pueden colapsar el hosting

backups WordPress | vídeos WordPress | almacenamiento S3 | restauración WordPress | biblioteca multimedia

Fuente: https://mantenwp.com/tus-backups-de-videos-pueden-colapsar-el-hosting/
Cuando los vídeos crecen sin control, cada copia de seguridad puede convertirse en una carga crítica para el servidor. Separar archivos multimedia, datos y código evita ZIP masivos, reduce fallos y acelera las restauraciones.

El backup nocturno puede empezar bien y terminar bloqueando el panel, llenando el disco y dejando un ZIP inútilmente enorme cuando mezcla años de vídeos, miniaturas y duplicados.

Los backups para sitios con grandes attachments (vídeos) deben separar base de datos, código y `uploads`: así se evitan timeouts, sobrecostes y restauraciones que obligan a descargar cientos de gigas para recuperar un solo archivo.

Decide según GB, hosting y ventana disponible

La estrategia depende del tamaño de la biblioteca, de los cambios diarios y de las horas disponibles para copiar sin afectar a visitantes, ventas, clases o publicaciones.

Los cinco datos que debes medir

Mide el tamaño total de `uploads`, el crecimiento mensual, los GB modificados cada semana, la cuota libre real, la memoria PHP, el límite de ejecución y el ancho de banda de salida. También identifica dónde se ejecuta la tarea: WP-Cron depende de las visitas y puede retrasarse o acumular procesos, mientras que un cron real del servidor funciona como un reloj independiente y suele ser más fiable para copias largas.

Un servidor con 100 GB libres no dispone necesariamente de margen para generar un ZIP de 70 GB, porque necesita conservar originales, temporales y el archivo final.
