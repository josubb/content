Configurar mal Redis o Memcached rompe tu carrito

Redis para WooCommerce | Memcached | caché de objetos | rendimiento WordPress | TTFB logueado

Fuente: https://mantenwp.com/configurar-mal-redis-o-memcached-rompe-tu-carrito/
Un caché mal configurado puede acelerar la primera carga y, al mismo tiempo, invalidar el carrito justo cuando el usuario está listo para pagar. Redis y Memcached reducen el TTFB, pero solo si cada dato dinámico del checkout se excluye, segmenta y valida correctamente.

Lanzas una campaña, suben los usuarios logueados y la portada sigue cargando rápido. Sin embargo, el carrito tarda, el checkout responde a trompicones y algunos precios o cantidades parecen no actualizarse como deberían. La caché de página no toca esas zonas dinámicas: una caché de objetos mal configurada puede convertir una mejora esperada en un riesgo directo para las ventas.

Redis vs Memcached para WooCommerce: ¿cuál elegir? Para la mayoría de tiendas WooCommerce, Redis es la opción más segura: aporta caché de objetos persistente, estructuras de datos flexibles y mayor control con sesiones, precios dinámicos o picos de tráfico. Memcached encaja en instalaciones sencillas sin necesidad de persistencia. Antes de activarlos, mide el TTFB con usuarios logueados y valida qué datos de WooCommerce deben quedar fuera de caché.

Redis encaja en tiendas WooCommerce complejas

Redis suele ser la elección segura para una tienda WooCommerce con sesiones, reglas de precio o picos de compra. Guarda datos en memoria, como una mesa de trabajo mucho más rápida que buscar cada documento en un archivador MySQL, y puede conservarlos tras un reinicio mediante persistencia RDB o AOF, según la configuración del servidor.

Memcached también guarda datos en memoria, pero está pensado para información temporal. Si el proceso se reinicia, su contenido desaparece. Eso no rompe WooCommerce por sí mismo, porque la base de datos sigue siendo la fuente real, pero puede devolver carga a MySQL justo durante una campaña.

La elección útil: Redis para tiendas con clientes recurrentes, B2B, multimoneda, suscripciones o integraciones.

*La diferencia entre un checkout rápido y una venta perdida puede estar oculta en una sola clave de caché...*
