La seguridad efectiva no debería convertir cada visita en una carga para el servidor. Una protección mínima y bien configurada bloquea amenazas comunes sin duplicar procesos ni degradar el rendimiento de WordPress.

No necesitas una suite pesada para proteger una web WordPress pequeña: los plugins de seguridad ligeros que limitan intentos de acceso, añaden autenticación en dos pasos y mantienen copias restaurables cubren los riesgos más comunes sin sobrecargar el hosting.

Tres capas bastan para una web pequeña

Una web pequeña queda bien cubierta con protección contra fuerza bruta, 2FA y copias restaurables.

Límite de intentos contra fuerza bruta

La limitación de intentos bloquea temporalmente una IP tras varios accesos fallidos. Para la mayoría de blogs y webs corporativas, un límite de entre 3 y 5 intentos durante 20 o 30 minutos es razonable. No conviene bloquear para siempre: una persona puede escribir mal una contraseña o cambiar de red móvil.

Un solo bloqueador de accesos es suficiente. Instalar dos plugins que cuentan fallos puede acabar bloqueando a un administrador legítimo sin que sepas cuál debe desbloquearse. Si el hosting ya ofrece esa defensa, no añadas otra sin una razón clara.

2FA y copias que sí salvan el día

La autenticación de dos factores pide la contraseña y un código temporal de una aplicación como Google Authenticator, Aegis o Authy. Actívala al menos para todas las cuentas con rol de administrador, y guarda los códigos de recuperación fuera de WordPress.

Las copias de seguridad son la red bajo el trapecio. Programa una copia diaria si publicas o recibes pedidos cada día, y una semanal si apenas cambias la web. Conserva entre 7 y 30 copias, según el espacio disponible, en un lugar externo como Google Drive, Dropbox, S3 o el sistema de tu proveedor.
